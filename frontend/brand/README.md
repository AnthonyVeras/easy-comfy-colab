# Logo v1

`logo-v1.png` is the original monochrome **ec** monogram generated for Easy Comfy Colab 2 with the built-in image generation tool. The Cobalt reference informed the restrained visual style; its logo was not used as an input or copied. The opaque dark background avoids the alpha artifacts found in the discarded first export.

The shared interface, favicon and desktop icon set consume this asset. `tauri icon frontend/brand/logo-v1.png` generates packaging sizes. `icon.svg` remains the earlier provisional icon source; it is not the current brand.

Final generation prompt:

> Use case: logo-brand. Create a single final square logo image for Easy Comfy Colab 2. A professional minimal app brand inspired by the monochrome utilitarian aesthetic of cobalt.tools, with an ORIGINAL symbol rather than copying Cobalt. Solid flat charcoal background #141416. Center one bold crisp warm-white #f2f2f0 geometric monogram: an open lowercase e interlocking with a c, two thick simple rounded bracket curves, very clean deliberate negative spaces. The abstract ec symbol should be compact, balanced, effortlessly legible at tiny app-icon sizes. Use simple flat vector-like shapes with completely uniform fills. Symbol covers 60 percent of the square, generous clear margins. No typography or words outside the monogram. No transparency, no texture, no noisy edge pixels, no outline, no gradients, no dimensional lighting, no shadow, no glow, no 3D, no mockup, no cloud, no robot, no circuit lines, no extra decorative elements. A precise clean mark on an even dark background only.
